## Lokaal controleren

Deze website heeft geen `dev:veilig`-script. Er is geen `.env`, sleutel of klantgegeven overgenomen. Controle gebeurt op de statische build via een eigen localhost-poort. De browserproef blokkeert alle externe requests en verstuurt geen formulier.

```sh
npm ci
npx tsc --noEmit
node scripts/check-aanbod.mjs
node scripts/proef-team-functies.mjs
npm run build
node scripts/proef-prerender.mjs
npm run preview -- --host 127.0.0.1 --port 4311 --strictPort
# In een tweede terminal; gebruik een lokaal beschikbare Playwright-installatie:
PLAYWRIGHT_CORE=/pad/naar/playwright/index.mjs BROWSER_CHANNEL=chrome node scripts/check-product-route.mjs
```

De screenshots worden standaard in `/tmp/socialnow-product-route` gezet; `ARTIFACT_DIR` kan dit veranderen. Schermbewijs van deze ronde staat buiten de bronmap in `~/SocialNow-OS/website-ux-01-20261006-evidence`: home, OS en aanbod op 390 en 1440 px voor nl/en/de/fr. Browsercontrole gebruikt Chrome, geen Safari of echte telefoon. De app-login is als bestaande link gecontroleerd; echte aanmelding en koppelingen vallen buiten deze websitewijziging.

De build genereert juridische PDF’s opnieuw. Die gegenereerde wijzigingen worden niet gecommit. Er is geen app-CSP/service-worker gewijzigd.

Oude proeven: `proef-steven-fincer.mjs` heeft op ongewijzigd `04f2556` al twee rode eisen (ABN AMRO/Fincer-volgorde en ABN-link). `check-hero-veilig.mjs` verwacht onder meer de oude OS-logo-intro, Artist-Impression-inhoud, de OS-film in de hero en verplichte Odoo-herotekst. De laatste twee eisen zijn door deze opdracht bewust vervangen. Deze legacyproeven zijn geen groen verklaarde acceptatiechecks voor deze wijziging.

De eerste JavaScript-bundel met statische imports is 125,0 KB gzip; de ongewijzigde basis heeft 124,2 KB. De oude 120 KB-grens is dus ook op main al overschreden. Deze ronde bespaart het vroeg laden van de OS-film en voegt circa 0,8 KB script toe. Geen claim van een lagere totale JavaScript-bundel.

Geslaagde acceptatiecontrole: volledige build (350 pagina’s), TypeScript, `check-aanbod`, `proef-team-functies`, `proef-prerender` en de acht Chrome-combinaties (nl/en/de/fr op 390 en 1440 px).
