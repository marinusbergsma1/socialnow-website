## Lokaal controleren

Deze website heeft geen `dev:veilig`-script. Er is geen `.env`, sleutel of klantgegeven overgenomen. Controle gebeurt op de statische build via een eigen localhost-poort. De browserproef blokkeert alle externe requests en verstuurt geen formulier.

```sh
npm ci
npx tsc --noEmit
node scripts/check-aanbod.mjs
node scripts/proef-team-functies.mjs
npm run build
node scripts/proef-prerender.mjs
npm run preview -- --host 127.0.0.1 --port 4311 --strictPort
# In een tweede terminal; gebruik een lokaal beschikbare Playwright-installatie:
PLAYWRIGHT_CORE=/pad/naar/playwright/index.mjs BROWSER_CHANNEL=chrome node scripts/check-product-route.mjs
```
