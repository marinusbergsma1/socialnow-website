# Tokens en prijzen op socialnow.nl, schermafdrukken 18 oktober 2026

Tak `claude/tokens-plus-site-84b6e3`. Gemaakt met een productiebuild (`npm run build`, `vite preview`) op 390 en 1440 px, in NL (`/nl`) en EN.
Voor de opname zijn de vaste header en de inschuifanimatie van de tegels uitgezet.

Model van Marinus, 18 oktober 2026 (gekozen in de sessie "SocialNow header A/B test versies", bevestigd door de coördinator):
alles maandelijks; gratis tot 10 GB met SEPA-machtiging bij aanmelding; tokens 1.000 / 2.500 / 5.000 voor €10 / €25 / €50 per maand;
hulppakketten vanaf €3.000 per maand met custom OS, gratis website en Connect. Plus €20 en het losse blok "OS op maat vanaf €10.000" zijn weg.
De prijs per hulppakket is nog niet bekend; de kaarten tonen daarom geen bedrag. Btw: "excl. btw" staat op één plek (`BTW_PER_MAAND` in `proposal/TokensPlus.tsx`).
